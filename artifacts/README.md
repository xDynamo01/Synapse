# Generated Artifacts

- `linkedin/`: generated publication images; ignored by default.
- `reports/generated/`: generated tool and audit outputs; ignored by default.
- `temporary/`: disposable local files; ignored.
- `diagrams/`: reserved for selectively versioned diagrams. Official architecture
  diagrams remain with their owning documentation under `docs/`.

Do not use this directory for source, fixtures, migrations, manifests, or
canonical documentation.
