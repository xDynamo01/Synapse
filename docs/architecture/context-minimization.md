# Context minimization and redaction

Minimization is local and deterministic. It includes relevant or mandatory
assets within the declared token budget and records every inclusion/omission
reason, original/final token estimate and residual risk. Context Fusion
preserves ownership, classification, categories and training-use metadata but
does not decide egress.

Supported text/structural operations are field removal, identifier
replacement/hashing, secret masking, schema extraction, structural summary,
code-symbol anonymization, metadata removal and transcript-segment removal.
Every redaction plan binds source and transformed checksums and validation
status. Failure closes external egress.

No real media-region redaction is claimed. Restricted audio/images use local
providers or are blocked from external processing.
