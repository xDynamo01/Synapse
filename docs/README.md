# Synapse 0.3 documentation

## Authority

1. The binding Decision Charter in `specs/` records approved product intent.
2. Approved specifications in `specs/` describe the clean-room target.
3. Approved execution roadmaps and task plans live in `superpowers/plans/`.
4. `reference/proposals/` contains user-supplied proposals awaiting
   reconciliation or retained for provenance.
5. `archive/pre-cleanroom/` contains historical evidence and inventory. It is
   not an active architecture or implementation source.
6. `assets/` contains approved or supplied visual references.

No archived claim is automatically valid for the new runtime. Every capability
requires new implementation and new evidence.
