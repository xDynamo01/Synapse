# Synapse Roadmap

The canonical Synapse V3 roadmap is [`docs/roadmap.md`](docs/roadmap.md).

The previous V2 phase list has been retired because it mixed completed,
experimental, and target behavior and treated the removed React/Tauri client as
the product direction. Historical backend decisions and validation evidence remain
available under `docs/adr/` and `docs/validation/`.

Use the canonical roadmap together with:

- [`docs/architecture.md`](docs/architecture.md) for system boundaries;
- [`docs/development.md`](docs/development.md) for validation gates;
- [`docs/security.md`](docs/security.md) for release blockers.
